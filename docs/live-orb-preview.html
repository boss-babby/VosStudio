Live AI orb — design preview

The same drawing as App::drawLiveOrb in src/win/live.cpp (Direct2D), reproduced on a canvas so the motion can be judged without Windows. Move the mouse near the orb, click it, double-click it.

Colours: connected = accent blue, listening = teal, thinking = violet with orbiting electrons, speaking = coral with the voice ring and ripples, error = red pulse, off = grey. Everything eases; nothing snaps.
